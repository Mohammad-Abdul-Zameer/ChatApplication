# Java Multi-Client Chat Application

A real-time chat application built using Java Socket Programming, Multithreading, Java Swing, and MySQL.

This project follows a client-server architecture where multiple clients can connect to a central server and exchange messages in real time. The server manages multiple connections using multithreading, while JDBC and MySQL are used to store chat history.

## Features

- Real-time messaging between multiple clients
- Client-server communication using Java Sockets
- Multithreaded server to handle multiple users
- User-friendly GUI using Java Swing
- Chat history storage using MySQL
- JDBC database connectivity

## Technologies Used

- Java
- Socket Programming
- Multithreading
- Java Swing
- JDBC
- MySQL

## Learning Outcomes

- Understanding TCP/IP communication
- Implementing client-server architecture
- Working with Java threads
- Building desktop GUI applications
- Connecting Java applications with databases
